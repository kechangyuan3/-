# 乡约码上行

根据本科毕业设计《“乡约码上行”数字游民乡村嵌入管理系统的分析与设计》第 3.1 节功能结构、第 4.2 节界面原型实现的响应式网页版应用。

## 六大板块

| 论文模块 | 本版可操作流程 |
| --- | --- |
| 用户管理 | 五类身份登录入口、头像中的个人资料与认证、统一申请记录 |
| 工位管理 | 搜索筛选、选择日期时段、可用座位检查、预约、当天签到、暂离、返回、结束、取消 |
| 出行管理 | 村庄详情、按目的地/预算/天数/偏好生成行程、查看删除行程、同行邀请 |
| 社区资源管理 | 闲置与技能搜索、发布资源、交换/互助申请、撤下发布、公共设施报修 |
| 活动管理 | 活动筛选、报名与取消、活动发起与审核发布、云认养意向、生长档案、村民动态提交 |
| 社区管理 | 发布动态、点赞、留言、社区公约、兼职项目与合作申请、管理员审核、统计和记录导出 |

## 使用

直接打开 `dist/index.html`，或在 `dist` 目录启动任意静态 HTTP 服务器，手机与电脑均适配。目前提供本地演示版本，尚未部署在线网址。

没有构建步骤与 JavaScript 第三方依赖。外部字体加载失败时自动回退到系统中文字体。图标与示意图使用项目内 SVG，场景照片为项目内的 AI 生成 WebP 素材。

资料与操作保存到当前浏览器的 localStorage（键 `xiangyue-v1`）。不同浏览器、设备与网址之间不共享数据。清除浏览器站点数据会清空记录。审核身份登录后，可在「社区审核 → 运营概览」导出 JSON 备份。

## 演示说明与后续接入

这是可运行、可交互的前端演示应用，不是原生 Android/iOS 安装包，也不是已具备真实交易能力的生产系统。

- 登录身份选择模拟论文中的用户分工，不构成后端权限隔离或真实登录。
- 认证、工位、活动、闲置、同行、兼职和认养均为演示记录，不联系真实商家、不收取费用、不承诺收益。
- 行程由本地规则生成，未接入地图、实时交通、真实住宿或 AI 服务。
- 认养生长记录为示例与管理员通过的本地更新，未接入真实农户视频或结算系统。
- 本版未实现摄像头扫码、人脸识别、实际支付、在线聊天、云端多人同步与真实收益分配。

正式上线需要服务端账号与权限、数据库及预约并发校验、商家与活动真实数据、地图服务、消息服务，以及合适的交易与认证流程。

## 验证

通过 JavaScript 语法检查与 Edge 浏览器自动化验证：六板块导航、表单提交、预约占位及状态流转、刷新保留记录、行程生成、资源发布及报修、活动报名、认养、帖子与留言、认证及管理员审核、审核通过后的活动发布。检查了 390px 手机宽度下所有主页面及子标签的横向溢出，并目视检查桌面和手机首页。

本项目不包含论文原文件、学号、论文正文或附件中的个人资料。

## 按身份呈现的界面

六大领域仍保留为系统结构。身份功能放在登录和头像入口，侧栏使用面向当前用户的任务名称，不直接展示论文中的“××管理”。

| 登录身份 | 五个服务入口 |
| --- | --- |
| 数字游民 | 找工位、去乡游、换好物、约活动、邻里圈 |
| 当地村民 | 共享空间、介绍村庄、邻里互助、我的认养、乡邻日常 |
| 企业 | 预约空间、探访乡村、资源合作、共创活动、招募人才 |
| 数字游民公社 | 工位运营、村庄展示、资源与报修、发起活动、公社日常 |
| 平台管理员 | 工位审核、村庄审核、资源审核、活动审核、社区审核 |

退出或切换身份会返回登录页，不删除演示记录。本版仍为单浏览器共享演示数据，没有服务端身份核验与数据隔离。资料提交与审核可跨演示身份验证；新空间与村庄的资料审核目前仅记录处理结果，未自动创建可预约库存或真实地图信息。

本轮验证覆盖五种身份的桌面与手机导航、全部子标签、头像资料、登录持久化、退出重登、原预约流程，以及村民提交空间资料到管理员审批的流程。

## HR 展示版视觉更新

- 8 张按内容生成的场景图：散养鸡、竹林办公、独立会议室、乡村全景、咖啡共创、竹林步道、稻田秋收、茶园新芽。
- 首页采用村庄全景与轻量悬浮信息卡；功能入口使用绿色、青蓝、淡紫和暖橙分色。
- 云认养新增林下散养鸡“小栗”，与稻田、茶树使用不同照片和独立数字档案。
- 认养详情支持生长动态、养护计划、认养说明切换；可保存、取消认养意向并在“我的参与”查看。
- 资源区使用对应显示器、相机、自行车、设计与公共设施的图形；社区动态配有在地场景图。
- 支持系统“减少动态效果”偏好。展示数字与养护内容为示例，未接入实时传感器、真实农户影像或收益结算。

图片使用内置 ImageGen 生成，提示词与路径详见“图片素材说明.md”。精简 WebP 图片位于 dist/assets。独立 HTML 已内嵌全部场景图，携带单个 HTML 文件即可展示；外部字体不可用时自动使用系统字体。

本轮验证：图片正常加载、认养档案三标签切换、保存意向与我的数字农场、预约确认及取消、资源搜索后保留图形、390px 宽度下六个主要页面不产生横向溢出。已保存桌面端云认养展示截图。
